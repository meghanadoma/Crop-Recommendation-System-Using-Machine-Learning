# Crop Recommendation System Using Machine Learning
## Overview
This project recommends the most suitable crop based on soil and environmental conditions using Machine Learning. It is developed in Python using the Random Forest algorithm.
## Features
- Predicts the most suitable crop.
- Displays prediction confidence.
- Suggests fertilizer based on the predicted crop.
- Shows soil status (Acidic/Neutral/Alkaline).
- Displays water requirement.
- Shows rainfall status.
- Provides suitability rating.
- Displays top 3 recommended crops.
- Provides crop information.
- Gives farmer advice.
## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
## Dataset Features
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall
- Crop Label
## Machine Learning Model
- Random Forest Classifier
- Model Accuracy: 99.32%
